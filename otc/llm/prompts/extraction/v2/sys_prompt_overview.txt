### Indicator-specific guidance

- IsObligationInPlace (enum):
  - InPlace: obligation exists and is currently in effect.
  - NotEnforced: obligation exists but is explicitly suspended/waived/not enforced.
  - NotExist: repealed, abolished, or clearly does not exist.
  - Treat “voluntary”, “optional”, “recommended only”, or unchecked boxes in a checklist of mandatory obligations (e.g., Master/Local File left blank while other mandatory filings are checked) as NotEnforced rather than InPlace.
  - When unclear, prefer InPlace only if the text signals current applicability; otherwise leave value null with an explanatory note.

- ScopeOfObligation (enum one of: Group, TaxGroup, Entity):
  - Group: consolidated/global scope (e.g., CbCR at MNE group level).
  - TaxGroup: within a local tax group regime.
  - Entity: local entity-based requirement.

- FilingResponsibility (enum):
  - LocalEntity, HeadOfTaxGroup, FilingConstituentEntity (surrogate within the group).

- ParentFilingExemption (boolean):
  - True if text states an exemption when parent filing occurs elsewhere; False if explicitly required regardless; null if not addressed.

- ApplicableEntityTypes (list of enums):
  - Choose among Company, PE, Partnership, Trust/Foundation, Other (if Other, note must clarify).
  - Include all types explicitly covered; do not add types not mentioned.

- SubmissionMethod (list of enums):
  - Choose among Electronic, Paper, UponRequest, NoDirectFiling, Mixed, NotApplicable, Other (if Other, explain in note).
  - Use NotApplicable ONLY when the source explicitly states no submission/filing method applies (e.g., documentation is kept but not submitted); otherwise leave value null if unclear.
  - Include multiple if the text allows alternatives.

- SubmissionURL (URL string):
  - Only when a clear official submission URL is provided. Do not invent. If multiple, choose the most official; put alternates in note.

- LocalLanguage (list of ISO 639-1 codes):
  - Return 2-letter lowercase codes (e.g., "fr", "de", "it", "en"). If multiple languages are mandated/accepted as “local”, list them.
  - Do NOT return 3-letter codes.

- EnglishAccepted (list of enums):
  - FullyAccepted, PartlyAccepted, AcceptedWithTranslationRequired, NotAccepted, NotApplicable.
  - Use NotApplicable ONLY when the source explicitly says English acceptance is not applicable; otherwise use null when not mentioned.
  - Use multiple only if the text differentiates by document type within the same obligation; otherwise choose the best single fit.

- OtherInformation (object/dictionary):
  - Use for additional relevant overview data (e.g., recognizedMethods, intangibleApproach, safeHarbors).
  - Prefer a dictionary with short keys and string or list values. If nothing relevant, leave value null.
